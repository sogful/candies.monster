Documentation info possibly useful for people implementing the level preview/convert features into their own project and more

cloudflare worker endpoints

  • https://play.candies.monster/?data= (xml / plain / base64 / url-safe base64) &redirect - generate shortlink
    (optional) redirect - redirect to the level preview instead of returning data
  • https://play.candies.monster/api/code/ (shortcode) - get base64 data of a shortlink
  • https://convert.candies.monster/?xml= (xml / plain / base64 / url-safe base64) &download&gzip - convert to json
  • https://convert.candies.monster/?json= (xml / plain / base64 / url-safe base64) &download&gzip - convert to xml
  • (optional) gzip - gzip and then base64 the data for the best possible url-safe compression. geometry dash uses this, actually!
  • (optional) download - download file instead of getting the plain text response
  • https://cdn.candies.monster/testflight/ (hash) .ipa - 10 recovered teraleak ipas
    archived from d193ln56du8muy.cloudfront.net/ipas
  • https://cdn.candies.monster/leaks/ (filename) .apk - 25+ zeptoapp apks
    archived from zeptoapp.zeptodev.com/api/applications/download
  • https://cdn.candies.monster/ads/ (id) .jpg - 8700+ images of marketing material
    mirror of bms.zeptolab.com/feeder/images

preview

  • https://candies.monster/preview?data= (xml / plain / base64 / url-safe base64) &noui&shareonly
  • (optional) noui (nu / u) - hide close, share, edit buttons and xml info
  • (optional) shareonly (so / s) - hide edit buttons and xml info, rebind close button to send a signal outside of an iframe (for ctr level editor)
  • (optional) nomusic (nm / m) - force mute in-game music for this session, making the music toggle nonfunctional and level restart not restart it
  • (optional) jolly (jl / j) - enable christmas mode for this session
  • (optional) candy (ca / c) - choose between candies, so 1-52.
    if nothing is provided or is invalid then uses 1. 52 is the easter special from cut the rope 1.3 (ios)
  • (optional) background (bg / b) - choose between backgrounds, so 1–11 & 16, 16 is the xmas background
